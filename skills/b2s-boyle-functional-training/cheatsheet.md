# Cheatsheet — New Functional Training for Sports (Michael Boyle)

Decision rules, thresholds, and fast heuristics — what Boyle would actually decide, not just what the words mean.

## Decision Rules

- **If** an athlete can't perform a bodyweight version of an exercise perfectly, **then** never load it — teach the pattern in warm-up, outside the weight room, before adding any external load ("adding strength to dysfunction").
- **If** an athlete's landing is loud, **then** the box/obstacle is too high — reduce height, don't push through.
- **If** landing knee-bend is visibly deeper than takeoff knee-bend, **then** the box is too high.
- **If** a coach or athlete is uncomfortable teaching/performing Olympic lifts, **then** don't use them — substitute medicine balls, kettlebell swings, or plyometrics.
- **If** an athlete's bench 1RM significantly exceeds their chin-up-equivalent 1RM (bodyweight + added load), **then** flag elevated shoulder-injury risk and increase pulling volume.
- **If** an exercise "doesn't look right," **then** it probably isn't right — regress immediately, don't add load to fix it.
- **If** a movement involves deep hip motion with minimal knee bend, **then** classify it as hip-dominant/deadlift-pattern; **if** it involves deep motion at both knee and hip, **then** classify it as knee-dominant/squat-pattern.
- **If** you must choose one lower-body test, **then** use the rear-foot-elevated split squat (5RM) over the back squat 1RM — safer, still valid.
- **If** an athlete has anterior knee pain and struggles with unsupported single-leg squats (but is fine on split squats), **then** suspect weak gluteus medius, not weak quads — use mini-band walks and cross-body reaching.
- **If** designing conditioning for a sprint-dominant/team sport, **then** never default to steady-state jogging/cycling — use tempo running → shuttle running instead.
- **If** a conditioning session isn't clearly >90% or <80% effort, **then** it's programmed wrong — there is no productive middle intensity (Francis's high-low rule).
- **If** technique breaks down in an Olympic lift, **then** the fix is almost always to reduce weight, not to keep pushing the same load.
- **If** an athlete can't move past Phase 1 of plyometric progression, **then** keep them there 2–3 more weeks — never force progress on a calendar.
- **If** you're deciding squat depth, **then** use femur-parallel-to-floor, never a 90° knee angle and never below "powerlifting parallel" for general athletes.
- **If** an athlete is a beginner designing their first program, **then** copy a proven program exactly (be a "cook") — don't mix multiple sources.
- **If** you want core rotational power for a striking/throwing sport, **then** train hip rotation via medicine ball throws — never load lumbar rotation.

## Threshold & Default Reference

| Metric | Value |
|---|---|
| Top-10%-of-sport benchmark: 10-yd dash (male / female) | <1.65 sec / <1.85 sec |
| Top-10%-of-sport benchmark: vertical jump (male / female) | >34 in (86 cm) / >25 in (64 cm) |
| Bodyweight exercise progression | 3×8 (wk1) → 3×10 (wk2) → 3×12 (wk3), then progress |
| Core isometric hold progression | 5×5-sec holds (25 sec total), building volume before duration |
| Plyometric foot-contact volume | ~25/day, ~100/week (intensity increases, not volume) |
| Weekly upper-body pulling minimum | ≥3 sets chin-up variation + ≥3 sets across 2 row variations |
| Push-pull ratio | Chin-up-equivalent 1RM ≥ bench press 1RM |
| Conditioning session intensity | >90% effort OR <80% effort — never in between |
| Conditioning workout density | ~16–20 sets per 1-hour session |
| Off-season strength phase length | 3 weeks/phase × 4 phases = 12-week cycle |
| Rotator cuff training rep range | 15–20 reps (high-rep, stabilizer-appropriate) |
| Medicine ball weight rule of thumb | If in doubt, go 2 lb (1 kg) lighter; if it looks too heavy, it is |
| Baseball overhead medicine ball weight | 4 lb (2 kg) |

## Decision Tree: Should I Load This Exercise?

1. Can the athlete perform the bodyweight version with correct technique (the "eye test")? **No** → stay bodyweight, work mobility/pattern in warm-up.
2. **Yes** → is this a joint that needs mobility (ankle, hip, thoracic spine, glenohumeral) or stability (knee, lumbar spine, scapula)? Mobility joints get warm-up/rolling/stretching work, not loading. Stability joints get progressive resistance.
3. Load only stability-need joints/patterns, using the Baseline → Progression ladder, adding weight or reps roughly weekly.
4. If technique degrades at any point ("doesn't look right"), drop back one regression level before continuing to add load.

## Decision Tree: Which Power-Development Method?

1. Need velocity-end-of-force-curve power, safely, with adjustable light load? → **Medicine ball throws** (light-implement).
2. Need to train reactive/elastic lower-body power using bodyweight? → **Plyometrics** (bodyweight), gated through Phase 1 landing competence first.
3. Need heavier-load power development? → Young/competitive athlete with no back-injury history and a coach competent to teach it → **Olympic lifts** (heavy-implement, hang position only). Adult/noncompetitive or coach not confident teaching → **Kettlebell swings** instead.
4. Healthy athletes should get exposure to all three methods, not just one.

## Tells & Smells

- Athlete reports "feeling a step slow" after a distance-running-heavy off-season → classic "train slow, get slow" symptom; check for excess steady-state volume.
- Knee pain described as "the knee caving in" → almost always a hip adduction/internal-rotation problem (weak gluteus medius), not a knee problem.
- Athlete strong on bench press but can't do a strict chin-up or push-up → push-pull imbalance, elevated shoulder-injury risk regardless of bench number.
- Coach describes lumbar "core rotation" stretches/exercises as a warm-up staple → outdated and risky per Sahrmann; redirect to thoracic mobility instead.
- Program built by copying "a little of this coach's stuff, a little of that coach's stuff" → the "recipe mixing" anti-pattern; Boyle predicts it will be a poor program regardless of the individual sources' quality.
- Athlete's box jumps are loud or the landing position is visibly deeper than takeoff → box is too high regardless of the athlete's confidence or ego.
