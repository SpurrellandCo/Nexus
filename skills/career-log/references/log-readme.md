# Career log

A running, dated record of what I've achieved at work, written while it's fresh so every resume is built from real facts instead of memory.

## How it's used

- `/career-log <what happened>` adds a win, goal, project, number, praise, promotion, certification or new skill. It asks only for what's missing: the number, my part, and who it helped.
- `/career-review`, every month or quarter, closes out goals, fills in missing numbers, confirms facts imported from old resumes, and asks about quiet stretches.
- `/career-interview` asks about my resume one bullet at a time (what was going on, what I did, how big it was, what changed, the tools, the hard part) and saves the answers here. It picks up where the last session stopped.
- `/resume-builder` makes two kinds of resume, picking the entries that fit and writing bullets only from them, never claiming more than the entry says:
  - a **master**, my best all-round resume. Once I approve it, it becomes the new baseline and the old one is kept in `baselines/`.
  - a **targeted** resume for one job, which starts from the current master and is tailored to that posting. It never changes the baseline.
- `/resume-update` adds to, tailors or refreshes an existing resume, or makes one my new master.

## What's here

| File | What it holds |
|---|---|
| `baseline.md` | My current master resume, word for word: the starting point for every targeted resume. Never edited; a new master replaces it. |
| `baselines/` | Earlier baselines, kept when a new master replaced them. |
| `profile.md` | Contact details, headlines and summaries I've used, skills, education, honors, and facts waiting to be confirmed. |
| `roles/` | One file per job, client engagement or venture, with dated entries. |
| `corrections.md` | Facts that were wrong and how they were fixed, so they never come back. |
| `resumes.md` | Every resume made from this log: when, for what, which entries, and what happened. |

Editing by hand is fine. Keep the entry format (see any role file) so the skills can still read it.
